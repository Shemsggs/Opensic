# Opensic roadmap

## v0.3 developer preview
Local library, favorites, playlists, direct streams, playback queue, seek, shuffle/repeat, background playback integration.

## v0.4
Separate state/service architecture, artwork caching, robust error handling, queue persistence, editable playlists, accessibility, widget and integration tests.

## v0.5 hybrid sources
Implement a Navidrome/Subsonic-compatible adapter for a user's own music server (credentials in secure storage, HTTPS, pagination, album art, API authentication). Separately integrate a properly licensed openly available catalog with API permissions for playback, search, and downloads as allowed. Provider-specific license terms must be verified before implementation.

## v1.0
Device QA, battery tests, media session reliability, offline caching with rights checks, signing and GitHub releases, privacy documentation, localization.
